SakilaTyperomMySQL
A Sakila database data synchronization and CLI tool built with TypeORM, supporting dual databases (MySQL/SQLite3) and providing full data synchronization, automatic entity generation, and unit testing capabilities.
Note: Part of the contents generated by AI.
Project Overview

Core Features: Full data synchronization for Sakila database dimension tables (e.g., film/actor/category).
Tech Stack: TypeScript + TypeORM + MySQL/SQLite3 + Commander (CLI) + Jest (Testing).
Highlights: Automatic database entity generation, command-line sync execution, and comprehensive test coverage.

Prerequisites

Node.js ≥ 14.17.0 (v16+ recommended for ts-node compatibility).
npm ≥ 5.2.0 (supports npx command).
Database: MySQL and SQLite3.
Optional Global Dependencies: npm install -g ts-node typeorm-model-generator.

Installation
1. Project Initialization
bash# 1. Initialize TypeORM project (MySQL template)
typeorm init --name SakilaTyperomMySQL --database mysql
cd SakilaTyperomMySQL

# 2. Install core dependencies
npm install sqlite3 --save          # SQLite3 database driver
npm install commander date-fns --save  # CLI tool + date handling

# 3. Install dev dependencies
npm install --save-dev ts-node typescript jest ts-jest @types/jest
2. Database Configuration
The project supports both MySQL and SQLite3. Modify the corresponding configuration file based on your needs.
2.1 MySQL
Edit src/data-source.mysql.ts:
typescriptimport { DataSource } from "typeorm";

export const AppDataSource = new DataSource({
    type: "mysql",
    host: "localhost",       // Database host
    port: 3306,              // Port
    username: "root",        // Your database username
    password: "your password", // Your database password
    database: "sakila",      // Target database (create in advance)
    entities: [__dirname + "/entity/**/*.ts"], // Entity file path
    synchronize: false,      // Disable auto-sync (prevents data overwriting)
    logging: false,
});
2.2 SQLite3
Edit src/data-source.ts:
typescriptimport { DataSource } from "typeorm";

export const AppDataSource = new DataSource({
    type: "sqlite",
    database: "sakila.sqlite", // Generated SQLite database file
    entities: [__dirname + "/entity/**/*.ts"],
    synchronize: false,
    logging: false,
});
3. Import Sakila Database Entities
Automatically generate TypeORM entity classes from an existing Sakila database (no manual coding required):
bashnpx typeorm-model-generator \
  -h localhost \       # Database host
  -d sakila \          # Database name (match config file)
  -u root \            # Username
  -x 'your password' \ # Password (add quotes for special characters)
  -e mysql \           # Database engine (mysql/sqlite)
  -o src/entity        # Entity output directory (must be src/entity)
Note: Generated entity files automatically map to database table structures and can be used directly for data operations.
